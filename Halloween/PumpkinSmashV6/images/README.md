# Image targets

The nine reference photographs, `image1.jpg` through `image9.jpg`, are listed in `manifest.json` and compiled by `../target-builder.html`. The manifest is the source of truth for which images are included in the target database. Each target can score only once per round.

MindAR tracks these exact flat images; it does not recognize similar objects. The wall around the detailed ball in `image2.jpg` has few distinctive visual features. If its recognition is unreliable, keep the printed ball pattern sharp, well lit, and in view, or replace the target with a more distinctive high-contrast photo and rebuild the database.

`image5.jpg` has relatively few distinct features outside the blue object. Keep that object in focus, well lit, and fully visible for best tracking.
