IMAGE BUILDER

Choose reference pictures from your computer, or load images already published in this project's images/ folder using images/manifest.json. This page compiles their visual features into a small image-tracking database. The compiler runs in your browser; the selected image files are not uploaded to a game server.

1. Add your images to the projectUse sharp, detailed, non-repetitive photos or illustrations. Keep the original image files in images/ for future updates.
2. Select the images or load the project folderFor the first build, select the same local files that you added to images/. The builder generates images-manifest.json so future builds can load published files from images/manifest.json. Choose 5 or more distinct images for the full hunt.
3. Build and upload the databaseUpload targets.mind and target-manifest.json beside index.html. Put the downloaded images-manifest.json into images/ and rename it manifest.json.

Important limitation: image tracking recognizes the actual flat reference image (for example, a printed picture or image displayed on a screen). It does not recognize a real 3D skeleton or object just because it looks similar to a photo. That type of object recognition needs a trained object detector.
