Target Builder

Compiles the photos listed in images/manifest.json into one tracking database (targets.mind) plus a manifest the game uses to double-check it. Everything runs in this browser tab, using the copy of the compiler stored in this project. Nothing is uploaded anywhere.

      Where the files go

      FilePut it inNotes
      targets.mindProject root (next to index.html)Replaces the old database. Must be uploaded together with the manifest below.
      target-manifest.jsonProject rootThe game checks the target count and sizes in this file against targets.mind.
      image1.jpg, image2.jpg, image3.jpgimages/ folderThe source photos. Nothing is downloaded for these; they are already there.
      images/manifest.jsonimages/ folderEdit this by hand to add, remove or reorder photos, then rebuild here.

      Filenames are case-sensitive on GitHub Pages: Image1.JPG is not image1.jpg.

      Adding or replacing a photo

      1. Copy the new photo into images/.
      2. Edit images/manifest.json: add or change an entry. Its position in the list is its target index.
      3. Reload this page, check the thumbnails, and press Build Image Database.
      4. Replace targets.mind and target-manifest.json in the project root and commit all changed files.

      Compiler: MindAR 1.2.5 (MIT), stored in vendor/mindar/.
