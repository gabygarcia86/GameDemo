# Image targets

This folder contains 31 reference images. `manifest.json` defines which images are compiled for tracking; image files not listed there are ignored by the builder.

To add, remove, or replace a target, update `manifest.json` as described in the project [README](../README.md), then rebuild both `targets.mind` and `target-manifest.json` from `target-builder.html`. The game round requires at least five listed targets and awards a maximum of one smash per image per round.

MindAR tracks exact flat images, not similar real-world objects. Sharp, distinctive, high-contrast photos with good lighting generally track best.
